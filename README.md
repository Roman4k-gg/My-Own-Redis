# Redis Clone in Go

In-memory база данных, совместимая с базовыми командами оригинального Redis. Проект написан с нуля на языке Go с использованием исключительно стандартной библиотеки.

## Цель проекта

Главной целью разработки было глубокое понимание внутренних механизмов работы Redis и улучшение навыков самостоятельного написания серверного кода. Вместо использования сторонних библиотек и готовых фреймворков, проект создавался с упором на понимание низкоуровневых процессов и сетевого взаимодействия.

## Чему я научился

В ходе реализации проекта были освоены и применены на практике следующие концепции:

- **Сетевое программирование:** Работа с "сырыми" TCP-сокетами, обработка множественных клиентских подключений и реализация Graceful Shutdown для безопасного завершения работы сервера.
- **Многопоточность (Concurrency):** Использование горутин для асинхронной обработки запросов. Безопасный доступ к общей памяти обеспечен через `sync.RWMutex`, что исключило состояние гонки (data races) при десятках тысяч параллельных операций.
- **Парсинг бинарных протоколов:** Написание собственного парсера для протокола RESP2 (REdis Serialization Protocol), что позволяет взаимодействовать с базой данных через стандартный клиент `redis-cli`.
- **Управление памятью (TTL):** Реализация пассивной экспирации ключей при чтении, а также активного Garbage Collector'а, работающего в фоновом режиме для очистки устаревших данных.
- **Персистентность данных:** Реализация механизма AOF (Append Only File) для логирования команд на жесткий диск и восстановления полного состояния базы данных после перезагрузки.

## Архитектура

Кодовая база разделена на независимые пакеты:
- `cmd/server` — точка входа, инициализация сервера и цикл принятия TCP соединений.
- `resp` — десериализация команд из сети и сериализация ответов сервера.
- `storage` — потокобезопасная in-memory хэш-таблица с механизмами экспирации и очистки.
- `handler` — маршрутизатор (роутер) команд базы данных (PING, ECHO, SET, GET, DEL, EXISTS).
- `aof` — модуль записи на диск и восстановления состояния.

## Запуск проекта

Для старта базы данных:
```bash
go run cmd/server/main.go
```

Для проверки всех механизмов (включая персистентность) предусмотрен тестовый скрипт:
```bash
python test.py
```
